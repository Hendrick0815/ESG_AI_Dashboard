# TEJ 日股價（開盤價、收盤價、成交量）

## 來源與匯出方式
- 來源：台灣經濟新報（TEJ）TEJ Pro，「特殊轉檔」整批匯出
- 匯出日期：2026-11-23
- 模組：
  - `adj`：TEJ 股價資料庫「調整股價(日)-除權息調整」
  - `unadj`：TEJ 股價資料庫「未調整股價(日)」
- 期間：2017-07-01 ～ 2026-10-20（研究資料截點）
- 市場：上市、上櫃、已下市、已下櫃普通股（TEJ 篩選「普通股」）
- 本資料夾只保留普通股代號：4 碼數字、不以 0 開頭、排除 91xx 存託憑證

## 核對結果
- 研究期間出現過的 976 檔上櫃普通股全部有資料（其中 20 檔已轉上市，資料在 `twse` 檔）。
- `unadj` 收盤價與櫃買中心 dailyQuotes 收盤價抽樣比對 45,354 筆，100% 完全一致。
- 開盤價缺漏或為 0 的比例約 0.006%。

## 用途
P1-2 交易時點修正：T 日收盤後形成訊號、T+1 日開盤成交。
隔夜與當日報酬以 `adj`（除權息調整後）計算，`unadj` 用於與交易所原始價格核對。
